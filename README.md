An entry for the [One Word From Grandma](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16) bounty on make.fun.

The task: send exactly one word — the word Grandma would text about AI.

Our word is **Chattycathy**. Grandma misremembers ChatGPT as a talkative
church lady named Chatty Cathy, and texts her by name.

`main.py` (Python 3.13, standard library only) writes that one word to
`/output/entry.txt`.
